# RESQ-MITRA

**BE FIRST TO RESPOND**

Flutter Android starter for RESQ-MITRA, with branded sign-in, emergency categories, emergency details, optional GPS capture, Firebase authentication/Firestore integration hooks, and an active-emergency status screen.

## Important safety note

This source is not a production-ready emergency dispatch system. It does not yet provide complete responder matching, guaranteed push-alert distribution, live responder tracking, or a fully audited authorization system. Firebase must be configured before sign-in or SOS submission can work. A successful Firestore write is not proof that a responder has been alerted. For real emergencies, contact local emergency services directly.

## Run locally

Requirements: Flutter stable, Dart SDK compatible with `pubspec.yaml`, and Android Studio/Android SDK.

```bash
flutter doctor
flutter pub get
flutter create --platforms=android --org com.resqmitra --project-name resq_mitra .
flutter run
```

## Firebase setup

1. Create a Firebase project and register the Android app using the application ID generated by Flutter.
2. Enable Email/Password authentication and Cloud Firestore.
3. Configure FlutterFire for your project and initialize Firebase with the generated platform options if required by your setup.
4. Apply restrictive Firestore security rules. Do not use open rules such as `allow read, write: if true`.
5. Test account creation, sign-in, denied permissions, network failure, and duplicate SOS submissions before any pilot.

The app intentionally keeps SOS submission disabled when Firebase initialization fails. Configure Firebase before expecting authentication and emergency records to work.

## Blood group selection

The emergency details screen asks for a blood group when the user chooses **General SOS** or **Blood Needed**. The selected group is included in the emergency description. Supported values: A+, A-, B+, B-, AB+, AB-, O+, O-.

## Build APK on GitHub

1. Create a GitHub repository.
2. Extract this project ZIP and upload/commit the **contents of this folder** to the repository root (so `pubspec.yaml`, `lib/`, and `.github/` are at the root).
3. Push to `main` or `master`, or open **Actions → Build RESQ-MITRA Android APK → Run workflow**.
4. When the workflow succeeds, open the run and download the `RESQ-MITRA-release-apk` artifact. Extract the artifact ZIP to get `app-release.apk`.

The workflow generates Android platform files, adds internet and location permissions, installs dependencies, and builds a release APK. This build workflow does not configure Firebase credentials or production signing.
